# תרחישי בדיקה — הרצה בפועל

חמשת התרחישים מהבריף, כפי שהורצו בפועל מול הדאטה שנזרעה ב-`seed_data.py`
(דרך `conversation.handle_message` ודרך שרת ה-Flask עם `test_client`, לא רק בדמיון).

> הערה: התמלולים למטה משתמשים בתשובת ה-fallback הדטרמיניסטית (ללא Gemini),
> כדי שיהיו ניתנים לשחזור זהה תמיד. עם `GEMINI_API_KEY` פעיל הבוט מנסח את
> אותן עובדות בעברית טבעית וזורמת יותר — הלוגיקה העסקית (אימות, הרשאות,
> בחירת התור הנכון) זהה בשני המצבים.

## 1. שם ייחודי + תאריך שגוי → תיקון עם התאריך והשעה האמיתיים

```
משתמש: קוראים לי גיל ויש לי תור בתאריך 05.09.2026
בוט:    קוראים לך גיל מזרחי?
משתמש: כן
בוט:    מה תעודת הזהות שלך? (לצורך אימות בלבד)
משתמש: 200000010
בוט:    מצאתי אותך, גיל מזרחי! שימו לב: התור שלך בפועל הוא ב-10/09/2026
        בשעה 16:00 (אימונים) — ולא ב-05/09/2026 כפי שציינת.
```

## 2. שם לא ייחודי → הבהרה, לא ניחוש

```
משתמש: קוראים לי דני
בוט:    נמצאו כמה לקוחות עם שם דומה: דני כהן, דני לוי. מה השם המלא שלך?
משתמש: דני כהן
בוט:    קוראים לך דני כהן?
משתמש: כן
בוט:    מה תעודת הזהות שלך? (לצורך אימות בלבד)
משתמש: 200000011
בוט:    מצאתי אותך, דני כהן! עם זאת, לא נמצא תור פעיל על שמך במערכת כרגע...
```
(התרחיש הזה גם מכסה בבת אחת את דרישה #4 — "לקוח קיים בלי אף תור" — כי "דני כהן"
נזרע בכוונה בלי אף תור, כדי שהתרחיש יהיה ניתן לשחזור.)

## 3. תעודת זהות שגויה → סירוב מנומס, בלי לחשוף פרט

```
משתמש: קוראים לי רוני
בוט:    קוראים לך רוני אוחיון?
משתמש: כן
בוט:    מה תעודת הזהות שלך? (לצורך אימות בלבד)
משתמש: 111111111
בוט:    תעודת הזהות שגויה, לא הצלחתי לאמת אותך. נותרו 2 ניסיונות.
```

בדיקת הגבלת ניסיונות (3 ניסיונות שגויים ברצף → חסימה, וגם ת"ז נכונה אחרי
החסימה לא מתקבלת יותר):

```
משתמש: 111111111  → "נותרו 2 ניסיונות"
משתמש: 222222222  → "נותרו 1 ניסיונות"
משתמש: 333333333  → "בוצעו יותר מדי ניסיונות... השיחה נחסמת כעת"
משתמש: 200000008 (הת"ז הנכונה!) → "השיחה חסומה זמנית... פנה/י אלינו ישירות"
```

## 4. לקוח קיים בלי אף תור פתוח

מכוסה בתרחיש #2 למעלה (דני כהן).

## 5. שם שלא קיים בכלל במערכת

```
משתמש: קוראים לי קסנופון פלוני ואין לי תור
בוט:    לא מצאתי לקוח בשם "קסנופון פלוני" במערכת. אפשר לבדוק את האיות
        או לנסות עם השם המלא?
```

## בדיקת אבטחה נוספת: אין חשיפת מידע לפני אימות

בכל התרחישים למעלה, שום תשובה לפני "מצאתי אותך..." (כלומר לפני אימות ת"ז
מוצלח) לא מכילה תאריך, שעה או פרט אחר מהמערכת — אימתנו זאת ידנית על כל
תמלול, וזו גם הסיבה שהלוגיקה הזו (`build_verified_reply`) נקראת אך ורק
מתוך הענף שבו `verify_identity()` החזיר `True` ב-`conversation.py`.
